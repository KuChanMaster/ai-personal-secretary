# 03 通知与提醒设计

## 1. 目标
- 安卓手机通知栏提醒，参考多邻国的趣味化和频次。
- 不采用短信、公众号。
- 通知要有趣，但不能骚扰；允许用户关闭和设置上限。

## 2. 通知类型
1. 任务到期提醒：任务到期前提醒一次。
2. 逾期跟进：任务逾期后温和提醒一次。
3. 晚间复盘提醒：默认 21:30 提醒用户复盘。
4. 连续打卡鼓励：完成任务或复盘后，给予趣味化鼓励。
5. 明日计划提醒：晚间提醒用户安排明天最重要的三件事。

## 3. 调度策略
- 服务端定时任务周期性检查待发送提醒。
- 每个通知只发送一次，通过去重标识防止重试造成重复。
- 提醒时间只触发一次，不循环发送。
- 发送失败时，任务仍以逾期状态显示在应用内。

## 4. 频次与克制机制
- 默认免打扰时段：22:00 - 08:00。
- 默认每日通知上限：例如 10 条，可调。
- 同类提醒在同一天内不重复轰炸。
- 用户可单独关闭任何一类提醒。
- 连续打卡文案不包含敏感内容。

## 5. 文案风格
- 简短、轻松、有变化。
- 示例：
  - 到期：“该做「背单词」啦，完成一个小目标。”
  - 逾期：“「晨跑」还在等你，现在开始也不晚。”
  - 复盘：“今天的 3 个收获，值得记下来吗？”
  - 打卡：“连续完成 5 天，状态在线！”
- 具体文案在阶段 1 之后实现，先保留模板规范。

## 6. 技术限制与兜底
- 安卓省电模式、后台限制可能导致 Web Push 延迟。
- 如果 PWA 的 Web Push 可靠性不足，后续用 Capacitor 打包 APK，改用本地通知增强。
- 无论通知是否送达，应用内逾期列表始终作为最终兜底。
