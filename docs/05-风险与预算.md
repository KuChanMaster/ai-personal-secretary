# 05 风险与预算

## 1. 隐私风险
- 风险：任务、复盘和偏好属于敏感个人数据。
- 控制：最小化收集、HTTPS 传输、云端行级权限、推送内容不直接暴露任务正文。
- 控制：提供隐私说明，列明使用的第三方服务。

## 2. 数据丢失风险
- 风险：手机丢失、误删、服务商故障。
- 控制：支持导出数据；云端自动备份；恢复演练；删除前二次确认。
- 控制：本地与云端都有数据副本，避免只依赖一端。

## 3. 离线同步风险
- 风险：多设备离线同时编辑产生冲突。
- 控制：MVP 采用“最后修改优先”，并保留删除墓碑。
- 控制：单人场景冲突概率低，后续必要时再升级同步方案。

## 4. API 密钥风险
- 风险：AI、邮件、推送密钥泄露。
- 控制：密钥只放服务端环境变量，不进前端代码和 Git。
- 控制：开发与正式环境分离，密钥最小权限，泄露可轮换。

## 5. AI 成本与滥用风险
- 风险：AI 调用失控产生费用或生成错误内容。
- 控制：AI 默认关闭；用户主动触发；设置每月软上限，默认 30 元，可调。
- 控制：限制单次输入输出长度；缓存重复请求；AI 只生成草案，用户确认后保存。

## 6. 外部服务风险
- 风险：Supabase、部署平台、推送服务涨价、停服或改变配额。
- 控制：数据可导出；正式使用前核对免费额度与付费规则。
- 控制：核心功能不依赖单一 AI 服务，AI 不可用时任务系统仍可用。

## 7. 删除影响说明
- 删除任务默认先归档或软删除，避免误删。
- 永久删除或删除账号前必须二次确认，并提示先导出数据。
- 删除账号会清除云端匿名身份下的数据，需在界面上明确告知影响范围。
